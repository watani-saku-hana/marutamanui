# marutamanui
丸玉ぬいはシンプルで作りやすい、小さなサイズのオリジナル汎用ぬい型紙シリーズです😋小さなマスコットからテーブル人形劇まで幅広く使え、市販の素体との組み合わせも可能です😊"Marutama Nui" is a series of original, versatile, and easy-to-make plushie patterns in compact sizes 😋. They are suitable for everything from small mascots to tabletop puppet shows and can even be combined with commercially available plushie bases 😊.
